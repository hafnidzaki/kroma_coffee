# KROMA COFFEE ROASTERS — E-Commerce Web Prototype

High-fidelity interactive prototype for **Kroma Coffee Roasters** (Specialty Coffee & Precision Equipment).

## 🚀 Live Demo
Once GitHub Pages is enabled, access the live mockup at:
`https://<your-username>.github.io/<repo-name>/`

## 📱 Features Included
- **Homepage (Beranda Lengkap):** Omni Search with suggestions, Category Mega Menu, Fulfillment Switcher (Kirim vs Ambil di Toko), Flash Sale countdown timer, Shoppable Barista Video Reels, Brand Showcase, Store Locator, and High-Contrast Footer.
- **Product Catalog & Facet Filters:** Real-time filter by roast level, processing method, and price range.
- **Product Detail Page (PDP):** Image gallery, tasting notes, grind size selector, packaging weight selector, and interactive brewing ratio calculator.
- **Shopping Cart & Checkout Flow:** Item steppers, promo vouchers (`KROMA50`), courier selection (JNE, SiCepat, GoSend).
- **Payment Gateway:** BCA Virtual Account (`8801 2345 6789 012`) with copy button, 24h countdown timer, QRIS instant barcode payment, and m-BCA transfer instructions.
- **Order Confirmed (Invoice):** Order `#KROMA-20261125-8849`, courier tracking link, and barista resting tips.
- **Authentication:** Login, Register with referral voucher `NEWROASTER50`, and Forgot Password recovery.
- **Store Locator & Click-and-Collect:** Information for Senopati, Bandung, Surabaya, and Semarang stores.
